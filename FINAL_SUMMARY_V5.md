## 🎯 Что было реализовано

### 1. Мастер привязки каталога (BindingWizard) ✅

**Назначение:** Админский инструмент для массового привязки внутренних компонентов к внешним продуктам из Open Food Facts.

**Ключевые возможности:**
- ✅ Очередь привязки, отсортированная по денежному весу
- ✅ Авто-кандидаты из OFF (1-3 предложения на компонент)
- ✅ Горячие клавиши: 1/2/3 для выбора, S для пропуска
- ✅ Ручной ввод штрихкода
- ✅ Настройка упаковки (размер + флаг округления)
- ✅ Прогресс-бар привязки

**Пример использования:**
```
Админ привязывает 34 из 60 компонентов за 20 минут
Это покрывает 95% денег всех походов
Остальные 26 (соль, специи) остаются с ручными ценами
```

### 2. Замены компонентов в походе (SubstitutionModal) ✅

**Назначение:** Локальная замена ингредиента в рецепте для конкретного похода без изменения каталога.

**Ключевые возможности:**
- ✅ Локальные замены (действуют только на один поход)
- ✅ Поиск похожих компонентов по категории
- ✅ Ratio для пересчёта (сушёное → свежее = 0.1)
- ✅ Визуализация замен (чип на карточке блюда)
- ✅ Список активных замен похода
- ✅ Возможность отмены замены

**Пример использования:**
```
В магазине не было гречки
Пользователь заменяет на рис (ratio 1:1)
Только этот поход пересчитывается:
- Меню: рис вместо гречки
- Закупка: рис 1.8 KG
- Сводки: новая стоимость
Каталог и другие походы не изменены
```

### 3. Расчёт закупок с учётом упаковок ✅

**Назначение:** Реалистичный расчёт закупок с округлением до упаковок и учётом остатков.

**Ключевые возможности:**
- ✅ Расчёт упаковок: `packs = ceil(need / pack_size)`
- ✅ Расчёт остатков: `leftover = buyAmount - need`
- ✅ Стоимость по упаковкам: `cost = packs × packPrice`
- ✅ Штучные товары (тушёнка): pack_size=1
- ✅ Развесные товары: pack_size=null
- ✅ Новые колонки в таблице закупок

**Примеры расчёта:**

| Продукт | Надо | Упаковки | Купить | Остаток | Стоимость |
|---------|------|----------|--------|---------|-----------|
| Гречка | 1.8 кг | 2 × 0.9 кг | 1.8 кг | 0 кг | 2 × 179₽ = 358₽ |
| Вода | 1.0 л | 1 × 1.5 л | 1.5 л | 0.5 л | 1 × 45₽ = 45₽ |
| Тушёнка | 8.2 шт | 9 × 1 шт | 9 шт | 0.8 шт | 9 × 210₽ = 1890₽ |
| Соль | 45 г | развес | 45 г | 0 г | 0.045 × 60₽ = 2.70₽ |

## 🏗️ Архитектура

### База данных

**Миграция V7__packs_and_substitutions.sql:**
```sql
-- Поля упаковок в ingredients
ALTER TABLE ingredients ADD COLUMN pack_size NUMERIC(14,3);
ALTER TABLE ingredients ADD COLUMN round_to_packs BOOLEAN NOT NULL DEFAULT FALSE;

-- Таблица замен
CREATE TABLE trip_ingredient_substitutions (
    id BIGSERIAL PRIMARY KEY,
    trip_id BIGINT NOT NULL REFERENCES trips(id) ON DELETE CASCADE,
    recipe_id BIGINT NOT NULL REFERENCES recipes(id) ON DELETE CASCADE,
    from_ingredient_id BIGINT NOT NULL REFERENCES ingredients(id) ON DELETE CASCADE,
    to_ingredient_id BIGINT NOT NULL REFERENCES ingredients(id) ON DELETE CASCADE,
    ratio NUMERIC(10,4) NOT NULL DEFAULT 1 CHECK (ratio > 0),
    comment VARCHAR(500),
    created_by BIGINT REFERENCES users(id),
    created_at TIMESTAMP NOT NULL DEFAULT now(),
    UNIQUE (trip_id, recipe_id, from_ingredient_id),
    CHECK (from_ingredient_id <> to_ingredient_id)
);
```

## 🚀 Как использовать

### Мастер привязки каталога

1. **Войти как админ** (admin@provision.app)
2. **Перейти в "Интеграции"**
3. **Нажать "Привязать каталог"**
4. **Для каждого компонента:**
   - Выбрать кандидата (клавиши 1/2/3 или клик)
   - Или ввести штрихкод вручную
   - Или пропустить (клавиша S)
5. **Настроить упаковку:**
   - Размер упаковки (например, 0.9 KG)
   - Флаг "округлять до упаковок"
6. **Завершить привязку**
7. **Прогресс виден на дашборде интеграций**

### Замены компонентов

1. **Открыть поход**
2. **Найти карточку блюда** (например, "Гречка с тушенкой")
3. **Нажать иконку замены**
4. **Выбрать компонент для замены** (например, гречка)
5. **Найти заменитель:**
   - Поиск по названию
   - Или выбор из похожих (та же категория)
6. **Установить ratio** (1:1 по умолчанию)
7. **Сохранить**
8. **Система пересчитывает:**
   - Меню: заменитель вместо оригинала
   - Закупка: новое количество
   - Сводки: новая стоимость
9. **На карточке блюда чип:** "замена: рис вместо гречки"
10. **Для отмены:** удалить замену из списка

### Расчёт закупок с упаковками

1. **Привязать упаковки** (через BindingWizard)
2. **Открыть "Закупка и чеки"**
3. **Видеть новые колонки:**
   - Надо (расход по меню)
   - Упаковки (количество × размер)
   - Купить (округлённое количество)
   - Остаток (разница)
4. **Система автоматически рассчитывает:**
   - Сколько упаковок купить
   - Какой будет остаток
   - Стоимость по упаковкам
