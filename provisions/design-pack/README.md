# design-pack · референс-пак айдентики «Провиант»

Пак кладётся в проект как есть (например, в `design/` или `docs/design/`) и
служит единственной точкой правды для кодинг-агентов и разработчиков.
Версия 1.1 · темы: dark (дефолт) + light · знак v4.

## Что внутри
| Файл | Зачем |
|---|---|
| `AGENTS.md` | инструкции агентам: порядок работы, жёсткие правила, чек-лист PR |
| `tokens.css` | CSS-токены обеих тем + утилиты; подключается первым |
| `tokens.json` | те же токены машинно-читемо (цвета, тип, ритм, z, a11y, logo) |
| `brand.md` | знак: история, геометрия, версии, охранное поле, don'ts, роли палитры |
| `components.md` | спецификации всех компонентов кита: структура, состояния, поведение, a11y, React-памятка |
| `assets/` | mark.svg, mark-light.svg, mark-mono.svg, favicon.svg, app-icon.svg, logo-horizontal.svg |

## Быстрый старт
1. Скопируйте папку в проект.
2. Подключите `tokens.css` до остальных стилей; на `<html>` поставьте
   `data-theme="dark"` (или отсутствие атрибута) / `"light"`.
3. Агент начинает с `AGENTS.md`; человек — с `brand.md`.
4. Эталоны визуально: `site/brand-book.html` (витрина, секции 06/09/10)
   и `site/index.html` (продукт с переключателем темы) из родительской папки.

## Договорённости
- Компоненты не содержат hex — только `var(--…)`; новые токены добавляются
  одновременно в `tokens.css` и `tokens.json`.
- Знак не перерисовывается: нужная версия берётся из `assets/`
  (dark → mark.svg, light → mark-light.svg, печать → mark-mono.svg).
- Новый компонент сначала описывается в `components.md`, затем реализуется.
- Темы не ветвятся в компонентах: только токены + `data-theme` на `<html>`.
