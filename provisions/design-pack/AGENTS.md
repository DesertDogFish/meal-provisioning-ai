# AGENTS.md — инструкции кодинг-агентам «Провианта»

Читаешь этот файл перед тем, как трогать UI. Пак лежит в `design-pack/`
(токены, спецификации, ассеты). Канонические реализации-примеры:
`site/index.html` (продуктовые поверхности), `site/brand-book.html` (витрина кита),
`site/theme.css` (токены для боевого сайта).

## Порядок работы
1. Прочитай `tokens.json` → `brand.md` → `components.md` (в этом порядке).
2. Пиши разметку/стили только по спецификациям `components.md`.
3. Новый компонент = сначала запись в `components.md` (структура, состояния,
   поведение, a11y), потом код. Без спеки — не мержим.
4. После сборки сверь визуально с `site/brand-book.html` (секции 06, 09, 10).

## Жёсткие правила
- **Никаких hex-литералов в компонентах.** Только `var(--…)` из `tokens.css`.
  Исключение — SVG-ассеты знака (они неизменяемы).
- **Темы:** тёмная — дефолт (`:root`), светлая — `html[data-theme="light"]`.
  Компонент не знает о теме: меняются только токены. Запрещены
  `@media (prefers-color-scheme)`-ветки и if-тема в JS-стилях.
  Переключатель: кнопка с `aria-label`, персист в `localStorage['pv-theme']` в try/catch.
- **Знак:** брать только из `assets/`. На тёмном — `mark.svg`, на светлом —
  `mark-light.svg`, печать/один цвет — `mark-mono.svg`. Не перерисовывать,
  не перекрашивать, не добавлять эффекты. Охранное поле 1/6 ширины,
  минимум 24 px (ниже — favicon-версия).
- **Акценты по ролям:** огонь (`--amber-*`, `--grad-brand`) — CTA, ключевые
  цифры, парус; вода (`--wave-*`) — статусы, метрики, волна; снег — заливки
  на огне и шапка знака. Не смешивать роли.
- **Текст на огне:** `--on-fire` (тёмный в dark, светлый в light). Мелкий текст
  на градиенте не пишем вообще.
- **Скругления:** только `--r-sm/md/lg/pill`. Карточки `--r-lg`, контролы `--r-md`
  или pill, чипы/бейджи pill или `--r-sm`.
- **Тени:** только `--shadow-1` / `--shadow-glow`. В светлой теме они
  переопределяются токенами автоматически.
- **Фокус:** `:focus-visible` — кольцо `2px var(--amber-500)`, offset 2px.
  Убрать outline без замены запрещено.
- **Движение:** длительности `--t-fast/base/slow`, кривая `--ease`.
  Всё декоративное (float, drift, pulse) глушится при `prefers-reduced-motion`.
- **Оверлеи:** поповеры `--z-pop`, модалки `--z-modal`, тосты `--z-toast`,
  nav `--z-nav`. Esc закрывает верхний оверлей; клик по оверлею закрывает модалку;
  фокус возвращается на триггер.
- **Контраст:** не ниже пар из `tokens.json → a11y.contrast`. Акцент-текст в
  светлой теме — `--amber-300` (#D97418), не тёмный #FFC46B.

## Именование
- CSS-переменные — как в `tokens.css` (`--bg-1`, `--text-2`, `--grad-brand`…).
  Не вводить синонимы (`--surface`, `--primary`): маппинг живёт только в токенах.
- Классы компонентов — префикс домена не нужен внутри продукта
  (`.btn`, `.card`, `.dp`, `.chip2`…); в сторонних интеграциях — префикс `pv-`.
- data-атрибуты состояний: `data-theme`, `data-val`; семантика — aria, не классы.
