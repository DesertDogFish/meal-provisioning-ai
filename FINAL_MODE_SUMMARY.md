## 🚀 Как использовать

### Переключение режима

1. **Кликнуть на бейдж** в правом верхнем углу
2. **Выбрать режим:**
   - Бэкенд (REAL) - HTTP запросы к API
   - Демо-данные (MOCK) - локальные данные
3. **Проверить соединение** - кнопка в модалке
4. **Сбросить демо-данные** - очистка localStorage

### Автоматический фолбэк

В режиме AUTO:
1. Приложение проверяет доступность API
2. Если API недоступен → автоматический фолбэк на мок
3. Показывается янтарный бейдж + баннер с причиной
4. При восстановлении API → тост с кнопкой переключения

### Ручное переключение

1. Клик на бейдж
2. Выбор режима в модалке
3. Кеш очищается автоматически
4. Все данные перезагружаются
