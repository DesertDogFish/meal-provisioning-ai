## E2E-B1. Баннер «Вы офлайн» не показывается — компонент не смонтирован
Компонент `src/components/NetworkStatus.tsx` рендерит баннер, но нигде не импортируется
(в `src/` нет ни одного использования, кроме собственного объявления). Пользователь при
потере сети не видит предупреждения, хотя состояние офлайна обрабатывается.
Сломано: 3 e2e-теста (`api-offline` OFFLINE-01/02, `offline` shows offline banner).
Приёмка: баннер виден в приложении при `context.setOffline(true)`; тесты выше зелёные;
`npx vitest run src/components` зелёный (добавить юнит на рендер при offline).

## E2E-B2. Фокус не возвращается на кнопку после закрытия модалки приёма (a11y)
`e2e/navigation.spec.ts` N-6: после Esc в модалке «Добавить приём пищи» фокус остаётся
в никуда (`toBeFocused` → inactive). Нарушает требование возврата фокуса на триггер.
Приёмка: после Esc `document.activeElement` — та же кнопка; тест N-6 зелёный.

## E2E-B3. Карточка похода не появляется после сида (E2E-05/09/10 таймаут 30 с)
Тесты сидят данные, видят текст «Тестовый маршрут», но локатор
`[data-testid^="trip-card-"]` не находит элемент. testid в коде присутствует
(`src/pages/TripsPage.tsx:425`). Нужно понять, что рендерится вместо карточки
(пустое состояние/скелетон/другой компонент) — возможен регресс списка походов.
Приёмка: разобрана причина, карточка рендерится, E2E-05/09/10 зелёные.

## E2E-B4. Текст дев-бейджа режима скрыт на десктопе
`span.api-badge__text` присутствует в DOM, но `hidden` на десктопном viewport; правило
сокрытия находится в `@media (max-width: 399px)` (`src/styles/nowrap-mobile.css:55`) —
то есть на 1280px срабатывать не должно. Сломаны E2E-06/07/08.
Приёмка: на десктопе текст бейджа виден, на ≤399px скрыт (как задумано); три теста зелёные.
