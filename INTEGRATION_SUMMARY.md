## 🔑 Ключевые особенности

### 1. Конвертация цен
```
packPrice / packAmountInIngredientUnit = unitPrice

Пример:
- Внешний продукт: 900 г, 89.99 ₽
- Внутренний ингредиент: KG
- Результат: 89.99 / 0.9 = 99.99 ₽/KG
```

### 2. Защита ручных цен
- Цены с `source=MANUAL` не перезаписываются
- Можно комбинировать ручные и автоматические цены
- Прозрачность: виден источник каждой цены

### 3. Фильтрация
- Только валюта RUB
- Только валидные цены (> 0)
- Только совместимые единицы измерения

### 4. Расширяемость
- Интерфейс `PriceProvider` позволяет добавлять новые провайдеры
- Архитектура не требует изменения основной логики
- Можно добавить X5, Магнит, Ozon и другие
