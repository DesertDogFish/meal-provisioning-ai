## 📊 Бизнес-логика

### Проверка дублей

**Жёсткий дубль:**
- name_norm + unit совпадают
- → 409 DUPLICATE_PRODUCT
- → Нельзя сохранить

**Мягкий дубль:**
- name_norm совпадает, unit разный
- → Предупреждение в UI
- → Можно сохранить

### Правила обновления

**Занятый продукт (используется в рецептах):**
- Нельзя менять имя и единицу → 409
- Можно менять категорию, упаковку, калорийность

**Свободный продукт:**
- Можно менять всё
- Проверка дублей при изменении имени/единицы

### Удаление

**Занятый продукт:**
- → 409 PRODUCT_IN_USE
- Нельзя удалить

**Свободный продукт:**
- → 204 No Content
- Можно удалить

## 🚀 Как использовать

### Создание продукта

1. Войти как админ
2. Перейти в "Продукты"
3. Нажать "+ Продукт"
4. Ввести название (live-проверка дубля)
5. Выбрать категорию из дропдауна
6. Выбрать единицу (KG/L/PCS)
7. Ввести упаковку (опционально)
8. Отметить "округлять закупку до упаковок" (опционально)
9. Ввести калорийность (опционально)
10. Нажать "Сохранить"

### Фильтрация и сортировка

1. Ввести запрос в поиск
2. Выбрать фильтры (категория, единица, цена, интеграция, использование)
3. Кликнуть на заголовок колонки для сортировки
4. Кликнуть ещё раз для изменения направления
5. Нажать "Сбросить фильтры" для очистки

### Обновление продукта

1. Нажать иконку правки на продукте
2. Изменить данные в модалке
3. Нажать "Сохранить"

### Удаление продукта

1. Нажать иконку удаления
2. Подтвердить удаление (если продукт свободен)
