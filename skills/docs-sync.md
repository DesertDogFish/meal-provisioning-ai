# Skill: документация — что можно править и что обновлять

## Белый список MD (новые MD-файлы — только внутри него)
- `AGENTS.md` — правила (короткий, ссылки на skills/).
- `skills/**.md` — инструкции-скиллы (≤ 80 строк каждый).
- `tasks/**.md` — задачи и пачки багов (`skills/create-task.md`).
- `tasks/done/**` — НЕ редактировать (история).
- `README.md` — запуск, стек, демо, траблшутинг.
- `ARCHITECTURE.md` — только факты, контракты и ADR (правила правок — в шапке файла; история задач сюда НЕ пишется).
- `backend/README.md` — документация бэкенда.
- `provisions/design-pack/**.md` — источник правды дизайна.
- `plans/backlog.md`, `plans/knownbugs.md`, `PLAN.md` — заглушки «расформировано», не наполнять.

Запрещены: `_REPORT.md`, `FINAL_*.md`, `*_SUMMARY.md`, отчёты отдельными файлами —
отчёт пишется в чат (формат `skills/close-task.md`) и в «Результаты» файла задачи.

## Карта R11 «изменение → какой док обновить» (в той же сессии, не «потом»)
| Меняется | Обновить |
|---|---|
| Схема БД / миграция | `backend/README.md` §Миграции, `ARCHITECTURE.md` §Database (см. `skills/migrations.md`) |
| Конфиг (application.yml, env, compose) | `README.md` (запуск/«Частые проблемы»), `backend/README.md`, `.env.example` |
| Контракт эндпоинта (DTO, коды, права, лимиты) | `ARCHITECTURE.md` §API-контракт/§Security + mock-слой + contract-тест (R3) |
| Математика денег/ккал/единиц | `ARCHITECTURE.md` («Эталон округлений», «Core Calculations») |
| Поведение, видимое пользователю | `README.md` |
| Дизайн/UX-паттерн | `provisions/design-pack/` + `src/index.css` токены |
| Правила работы агентов | `AGENTS.md` / соответствующий `skills/*.md` |

## Антисоветы (урок «Flyway V1–V29»)
- В прозе НЕ дублировать то, что стареет молча: номера версий, число миграций, списки
  файлов, количество строк. Вместо числа — ссылка на источник правды (каталог, pom, package.json).
- Длинные пересказы кода в MD запрещены: док описывает КОНТРАКТ и РЕШЕНИЯ, код — код.
- Ссылки в MD — относительные пути от корня репо; после переноса файла задачи обновлять
  ссылки НЕ в архивах `tasks/done/` (заморожены), а только в живых доках.
