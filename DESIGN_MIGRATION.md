## 10. Переносы: что запрещено разрывать (2026-10-29)

Правило из `plans/done/2026-10-29-ui-nowrap-and-mobile.md` (подзадача 1). Реализация —
утилитарные классы в `src/index.css`, а не точечные `white-space: nowrap` в разметке.

**Смысловая связка** — значение вместе с его подписью, единицей или иконкой подсказки.
Связка неделима: на любой ширине экрана (360 / 390 / 768 / 1440 px) она либо стоит на
строке целиком, либо **переносится целиком** на следующую. Разрыв внутри связки запрещён.

### Типы связок

| Тип | Пример | Класс |
|---|---|---|
| число + валюта/единица | `10 938 ₽`, `1,25 кг`, `8 шт`, `520 ккал` | `.keep-num` |
| подпись + иконка подсказки | `Думали ₽ ⓘ`, `Отклонение ⓘ`, `Стоимость ⓘ` | `.keep-pair` |
| подпись + число | `Думали: 10 938 ₽`, `Взято 3 из 12` | `.keep-pair` (число внутри — `.keep-num`) |
| знак статуса + текст | `✓ Меню собрано`, `⚠ взяли меньше` | `.keep-pair` |
| несколько связок в строке | строка итогов `Думали · Заплатили · ±%` | `.keep-pairs` (родитель, `flex-wrap`) |

### Классы

```css
.keep-pair        /* inline-flex, align-items: center, gap: var(--sp-1), nowrap */
.keep-pair-center /* явный алиас того же — для связок с иконкой/чекбоксом */
.keep-num         /* nowrap + font-variant-numeric: tabular-nums */
.keep-pairs       /* контейнер связок: flex-wrap — переносятся ЦЕЛИКОМ, по одной */
```

Выравнивание `center`, а не `baseline`: у иконки-кнопки `InfoTip` базовая линия —
низ её контент-бокса, и `baseline` поднимал бы «?» над строкой подписи.

Только токены дизайн-пака (`--sp-1`); литералов нет. Внутри `.keep-pair` допускается
вложенный `.keep-num` — внешний `nowrap` наследуется.

### До / после

Было (владелец, 29.10.2026): «Думали ₽» уходит на одну строку, иконка подсказки —
на следующую; «Отклонение» + иконка — то же; при этом «Стоимость 10 938 ₽» и её
иконка переносятся вместе. Три разных поведения на одной странице.

```html
<!-- было: перенос между подписью и иконкой произвольный -->
<th>Думали ₽ <InfoTip text="…" /></th>

<!-- стало: связка неделима, а число не рвётся между цифрами и ₽ -->
<th><span class="keep-pair">Думали <span class="keep-num">₽</span> <InfoTip text="…" /></span></th>
```

### Исключение и границы

- На ширине < 360 px связка **может переноситься целиком** (нерушимая пара уезжает
  на следующую строку), но не разрывается внутри. Горизонтальный скролл страницы
  из-за связки — дефект: значит, формулировку надо сократить, а не перенести.
- Если `nowrap` в шапке таблицы делает колонку шире экрана — сокращаем подпись
  («На человека за приём» → «На чел./приём»), а не разрешаем перенос.
- Печать (`.print-doc`, `TripPrintPage.tsx`) — правило действует, но мобильные

### Подсказки на тач-устройствах

Нативный `title` у `InfoTip` на телефоне не показывается (нет ховера) — связка
«подпись + ⓘ» была бессмысленной. `InfoTip` переведён на управляемый поповер
(портал в `document.body`, `position: fixed`, слой `--z-pop`, расчёт позиции —
`src/utils/dropdownPos.ts`): открытие тапом/кликом, фокусом с клавиатуры и ховером
на устройствах с мышью; закрытие по Esc, клику вне и уходу фокуса; фокус возвращается
на триггер; `role="tooltip"` + `aria-describedby`. Тач-таргет иконки ≥ 44×44 px —
«перчаточная» зона псевдоэлементом (`.infotip-trigger::after`), визуально иконка
остаётся 13 px. Ширина поповера ≤ `min(320px, 90vw)`, текст `--fs-small` (13 px).
