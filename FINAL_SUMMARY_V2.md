## 🔑 Ключевые особенности

### 1. Разделение плана и факта
```
План: из ingredient_prices (справочник)
Факт: из trip_price_overrides (оверрайды)
```

### 2. Правила разрешения цен
```java
if (override exists) {
    actualPrice = override.actualPrice
} else {
    actualPrice = plannedPrice
}
```

### 3. Формулы расчёта
```
plannedCost = amount × plannedUnitPrice
actualCost = amount × actualUnitPrice
deltaPercent = (actualCost - plannedCost) / plannedCost × 100
```

### 4. Изоляция данных
- Оверрайды не влияют на справочник
- Оверрайды не влияют на другие походы
- Синхронизация OFF не затрагивает оверрайды

## 🚀 Как использовать

### Интеграция с Open Food Facts

1. **Войти как админ** (admin@provision.app / password123)
2. **Перейти в "Интеграции"**
3. **Нажать "Подключить"** → увидите уведомление об успехе/ошибке
4. **Привязать ингредиенты** к внешним продуктам
5. **Нажать "Обновить цены"** для синхронизации

### Оверрайды цен

1. **Открыть поход**
2. **Перейти на вкладку "Закупка и чеки"**
3. **Для каждого ингредиента:**
   - Кликнуть на иконку редактирования (✏️)
   - Ввести фактическую цену из чека
   - Добавить комментарий (опционально)
   - Нажать ✓ или Enter
4. **Смотреть на sticky-итог:**
   - План: 2250₽
   - Факт: 2161₽
   - Дельта: -3.94%
