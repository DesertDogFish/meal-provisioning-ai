# Реализация каталога блюд: V2-V3 миграции и новый UI

## Выполненные задачи

### 1. Миграции базы данных

#### V2__catalog_extensions.sql
Расширение схемы каталога:
- Добавлено поле `code` (VARCHAR(64), UNIQUE) в таблицу `ingredients` для внешних интеграций
- Добавлено поле `category` (VARCHAR(40)) в таблицу `recipes` для категоризации блюд
- Добавлено поле `cook_minutes` (INT, NOT NULL, DEFAULT 0, CHECK >= 0) в таблицу `recipes` для фильтрации "без огня"
- Созданы индексы:
  - `idx_recipes_meal_category` для фильтрации по типу приёма и категории
  - `idx_recipes_cook` для фильтрации по времени готовки
  - `idx_ingredients_code` для поиска по коду

#### V3__seed_catalog.sql
Сид-данные каталога:
- **60 компонентов** с ценами на 01.01.2026:
  - Крупы (овсянка, пшено, гречка, рис, макароны и др.)
  - Молочные продукты (сухое молоко, яичный порошок)
  - Овощи (лук, морковь, картофель сублимированный)
  - Консервы (тушёнка говяжья/куриная, рыбные консервы)
  - Напитки (чай, кофе, какао)
  - Специи и добавки (соль, сахар, специи, сухофрукты)
  - И другие продукты для походных условий

- **61 блюдо** с полной структурой:
  - **Завтраки (15)**: каши, омлеты, блины, бутерброды
  - **Обеды (15)**: супы, вторые блюда, бутерброды
  - **Ужины (15)**: каши с тушёнкой, плов, макароны, супы
  - **Перекусы (16)**: ореховые миксы, шоколад, хлебцы, напитки

- Каждое блюдо имеет:
  - `name` - название
  - `meal_type` - тип приёма пищи (BREAKFAST/LUNCH/DINNER/SNACK)
  - `category` - категория (КАШИ/СУПЫ/ВТОРОЕ/БУТЕРБРОДЫ/ПЕРЕКУСЫ/НАПИТКИ/ВЫПЕЧКА)
  - `cook_minutes` - время готовки (0 для блюд без огня)
  - `calories_per_serving` - калорийность на порцию
  - `base_servings` - базовое количество порций (1 для всех блюд)
  - `ingredients` - список ингредиентов с количеством

- Граммовки указаны на 1 порцию (base_servings = 1), математика из спецификации работает без изменений

### 2. Обновление бэкенда

#### Entity
- **Ingredient**: добавлено поле `code` (String)
- **Recipe**: добавлены поля `category` (String) и `cookMinutes` (Integer)

#### DTO
- **IngredientRequest/Response**: добавлено поле `code`
- **RecipeRequest/Response**: добавлены поля `category` и `cookMinutes`

#### Repository
- **IngredientRepository**: добавлены методы `findByCode()` и `existsByCode()`
- **RecipeRepository**: добавлены методы:
  - `findByCategory(String category)`
  - `findByCookMinutes(Integer cookMinutes)`
  - `searchByNameOrIngredient(String search)` - поиск по названию или ингредиентам
  - `findWithFilters(MealType, String, Integer, String)` - комбинированная фильтрация
  - `countWithFilters(...)` - подсчёт с фильтрами

#### Service
- **IngredientService**: обновлён `createIngredient()` для поддержки `code`, обновлён `toResponse()`
- **RecipeService**: 
  - Обновлены `createRecipe()` и `updateRecipe()` для поддержки `category` и `cookMinutes`
  - Добавлен метод `getRecipesWithFilters()` для комбинированной фильтрации
  - Обновлён `toResponse()`

#### Controller
- **RecipeController**: обновлён `getAllRecipes()` для поддержки query-параметров:
  - `mealType` - фильтр по типу приёма пищи
  - `category` - фильтр по категории
  - `cookMinutes` - фильтр по времени готовки
  - `search` - поиск по названию или ингредиентам

### 3. Обновление фронтенда

#### Типы
- **Recipe**: добавлены поля `category?: string` и `cookMinutes?: number`

#### RecipesPage
Полностью переработанная страница каталога с новым UI:

**Фильтры:**
- Поиск по названию или ингредиентам (поддерживает запрос "тушенка" → все блюда с тушёнкой)
- Чипы типов приёма пищи с подсчётом (Все 61 / Завтрак 15 / Обед 15 / Ужин 15 / Перекус 16)
- Фильтр по категории (КАШИ/СУПЫ/ВТОРОЕ/БУТЕРБРОДЫ/ПЕРЕКУСЫ/НАПИТКИ/ВЫПЕЧКА)
- Тумблер "Только без огня" (cook_minutes = 0)
- Кнопка сброса фильтров

**Карточки блюд:**
- Название блюда
- Категория (бейдж)
- Время готовки или бейдж "без огня" (если cook_minutes = 0)
- Калорийность
- Количество ингредиентов
- Кнопка "В меню"

**Пагинация:**
- Кнопка "Показать ещё 24" вместо бесконечного скролла
- Предсказуемая навигация

**Пустое состояние:**
- Иконка и сообщение "Рецепты не найдены"
- Кнопка "Сбросить фильтры"

### 4. Тесты

#### CatalogIntegrationTest
Новый набор интеграционных тестов:

- **CAT-01** (P0): После миграций GET /recipes возвращает ≥ 50 блюд; состав каждого непустой
- **CAT-02** (P0): Фильтр mealType=BREAKFAST возвращает ровно 15; SNACK — 16
- **CAT-03** (P1): Поиск "тушенка" возвращает все блюда, содержащие beef_stew/chicken_stew (≥ 10)
- **CAT-04** (P1): Фильтр cookMinutes=0 возвращает только блюда "без огня" (22)
- **CAT-05** (P1): costPerServing в ответе считается по ценам на сегодняшнюю дату
- **CAT-06** (P2): Сортировка по калориям возвращает возрастающую/убывающую последовательность
- **CAT-07** (P2): Комбинированные фильтры работают корректно

## Ключевые возможности

### Фильтрация "без огня"
Отдельный сценарий для блюд без готовки:
- Обед на переходе
- Шторм на яхте
- Отсутствие горелки
- `cook_minutes = 0` вынесен в одно касание

### Поиск по ингредиентам
Запрос "тушенка" выдаёт все 12 блюд с тушёнкой — главный способ вспомнить "что у нас с ней готовилось"

### Быстрое добавление в меню
Кнопка "В меню" на каждой карточке (подготовка для модалки выбора дня/приёма)

### Плотная админ-таблица
Подготовка для админ-вида с колонками:
- Блюдо
- Тип
- Категория
- Готовка
- Ккал
- Себестоимость/порция
- В походах (занятость)
